Você é um arquiteto Java sênior. Preciso que implemente um sistema simples de descontos em Java puro, sem frameworks.

O sistema deve suportar três tipos de desconto: percentual, valor fixo e progressivo por quantidade. Quando um desconto for aplicado, o sistema deve notificar e salvar o resultado em memória.

Use Strategy para os tipos de desconto, Factory para criá-los, DiscountService para orquestrar, Repository para persistir em memória, DTO para transportar o resultado e Observer para notificar eventos.

Aplique SRP, OCP e DIP. Cada classe deve ter uma única responsabilidade, novos descontos não podem exigir alteração de código existente, e o Service deve depender de interfaces.

Máximo de 10 classes. Sem getters/setters desnecessários, sem código duplicado. Ao final, comente brevemente a responsabilidade de cada classe e qual princípio SOLID ela demonstra.
